# Panduan Proyek: Materi Kuliah Sistem Operasi

Proyek ini berisi materi kuliah Sistem Operasi (OS) untuk Program Studi Teknik Informatika,
Institut Teknologi Sumatera (ITERA), dipublikasikan di lectura.id.

## Panduan Membuat Slide

Semua panduan lengkap untuk membuat slide LaTeX Beamer ada di **`AGENTS.md`** di root proyek ini.
Baca file tersebut sebelum membuat atau memodifikasi slide apa pun.

## Command yang Tersedia

- `/make-slide` — Membuat slide baru untuk satu pertemuan. Definisi ada di `.claude/commands/make-slide.md`.

## Catatan Tambahan untuk Claude

- File slide disimpan di `1_Slides/weekN_slide.tex`.
- Gambar dari buku referensi ada di `2_Book_Translate/figures/`.
- Gunakan slide yang sudah ada (misal `week9_slide.tex` atau `week10_slide.tex`) sebagai referensi gaya terkini sebelum menulis slide baru.
